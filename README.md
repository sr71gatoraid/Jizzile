# Jizzile

Portable Windows audio-based aircraft/missile display with squad datalink. This repository hosts downloads; application source stays local.

[Download Jizzile 0.19.1](https://github.com/sr71gatoraid/Jizzile/releases/download/v0.19.1/Jizzile-0.19.1-Portable.zip) · [Release notes](https://github.com/sr71gatoraid/Jizzile/releases/tag/v0.19.1)

Extract the complete folder and run Jizzile.exe. Existing users can Check for updates; unchanged components are reused and personal Data/settings/calibrations are preserved. The 0.18.1 → 0.19.1 incremental update is approximately 1 MB.

0.19.1 stabilizes radar aircraft headings and missile arrows during rapid rolls and short camera/reference interruptions. Display continuity is bounded and does not delay or replace physical countermeasure inputs. It retains the audio efficiency improvements and existing sound profile.

Wired Quest uses Quest Link over USB plus SteamVR. Steam Link is not required. VR remains experimental: isolated checks do not establish actual flight registration or guaranteed target identity/reach. See the included README and release notes for limitations.
