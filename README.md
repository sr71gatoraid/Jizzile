# Jizzile

[Download the latest portable release](https://github.com/sr71gatoraid/Jizzile/releases/latest)

Current release: **0.20.2 — Close-approach countermeasure protection**.

Confirmed close raw-range approaches now take priority over optimistic passing estimates. Passing rejection elsewhere requires stronger evidence. This favors protection in close uncertain encounters and may dispense during close flybys. Audio does not establish ownership, seeker or guaranteed impact.

Extract the full portable folder and run `Jizzile.exe`. Existing users can use **Check for updates** to download only changed components. Preserve your personal `Data` folder.

Sound banks are unchanged. The reported VR marker visibility issue remains under investigation; this release does not claim to fix it. All in-game tests remain with users.

This public repository distributes binaries and update manifests. Application source remains local.
