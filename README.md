# Jizzile

Portable Windows audio-based aircraft/missile display with squad datalink. This repository hosts downloads; application source stays local.

[Download Jizzile 0.19.0](https://github.com/sr71gatoraid/Jizzile/releases/download/v0.19.0/Jizzile-0.19.0-Portable.zip) · [Release notes](https://github.com/sr71gatoraid/Jizzile/releases/tag/v0.19.0)

Extract the complete folder and run Jizzile.exe. Existing users can Check for updates; unchanged components are reused and personal Data/settings/calibrations are preserved. The 0.18.1 → 0.19.0 incremental update is approximately 1 MB.

0.19.0 reduces qualified audio measurement delay and decoder allocations, shares qualified capture timestamps between desktop and VR, and fixes a short-window audio ring failure. Production sound banks and calibration compatibility are retained.

Wired Quest uses Quest Link over USB plus SteamVR. Steam Link is not required. VR remains experimental: isolated checks do not establish actual flight registration or guaranteed target identity/reach. See the included README and release notes for limitations.
