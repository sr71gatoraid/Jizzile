# Jizzile

[Download the latest portable release](https://github.com/sr71gatoraid/Jizzile/releases/latest)

Current release: **0.20.3 — Gameplay reliability and protection feedback**.

Duplicate launches activate the existing radar. Saved game bindings are checked,
CM feedback distinguishes submitted keys from observed inventory changes, and
bounded diagnostics record useful failure context. Protection also retains
range-only contacts under active correction and recovers from transient input
rejection under existing rate limits.

Extract the full portable folder and run `Jizzile.exe`. Existing users can use
**Check for updates** to download only changed components. Preserve `Data`.

Sound banks are unchanged. Deployment feedback depends on fresh inventory evidence;
neither a key submission nor a count decrease proves a missile will be defeated.
The reported VR marker visibility issue remains unresolved. In-game tests stay
with users.

This public repository distributes binaries and update manifests. Application
source remains local.
