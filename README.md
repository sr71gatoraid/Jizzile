# Jizzile

Portable acoustic aircraft/missile tracking, radar and desktop markers, countermeasure assistance, HUD recognition, estimated launch reach and squad datalink.

Download the latest portable from [Releases](https://github.com/sr71gatoraid/Jizzile/releases/latest). Extract the entire folder and start **Jizzile.exe**. In Setup select War Thunder and install/verify the included sound mod with the game closed. Existing users can use the application's incremental Update command. Restart the game after sound-bank updates.

## Current: 0.17.0

Create or select a squad lobby and join without sharing a code. Listed lobbies are public; private invitations remain available. The release improves roll alignment, green/local duplicate handling, radar trail performance and missile-code overload recovery. It includes matching sound banks and preserves sound-selector junctions during refresh.

Read the bundled README.txt and SQUAD-LINK.txt for operation and network/privacy details. Send friends the clean portable ZIP, never your personal Data folder. No VPN or additional player dependency installation is needed.

This public repository distributes releases and incremental components. Application source remains local. Detailed maintainer documentation is private.

Audio estimates, telemetry, camera calibration, capacity and network freshness limit accuracy. The current sound layout has fourteen active missile codes and eight aircraft emitter codes; those are not unlimited or guaranteed unique-airframe contacts. Launch reach is an estimate, not a guaranteed hit. Public lobbies are open to anyone and do not provide secrecy from the relay. All in-game/headset validation remains the user's. No in-game accuracy or countermeasure-effectiveness guarantee is implied by isolated tests.
