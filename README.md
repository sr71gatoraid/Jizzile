# Jizzile

<img src="https://github.com/sr71gatoraid/Jizzile/releases/download/v0.12.5/Jizzile-Icon.png" width="128" height="128" alt="Jizzile cartoon missile icon">

Portable Windows audio-based radar and overlay. Built releases and incremental updates are public; source stays local.

[Download the latest portable build](https://github.com/sr71gatoraid/Jizzile/releases/latest/download/Jizzile-0.12.5-Portable.zip) · [Release notes](https://github.com/sr71gatoraid/Jizzile/releases/latest)

Extract the entire folder, run `Jizzile.exe`, and install/verify the matching sound mod. Existing users: **Settings > Advanced > Check for updates** after closing the game. Updates download changed files and preserve settings and compatible calibrations. No separate .NET installation or audio-routing driver is needed.

## Version0.12.5

- Independent audio-range approach protection can override faulty3D recession during rolls, missing reference poses or overhead viewing. Urgent approaches can qualify from2.8km; very close range emergencies can escalate to terminal bursts.
- Clear outgoing range trends and trusted range-consistent passing trajectories remain excluded. Finite stock, freshness, focus, manual-input and invalid-signal guards are retained.
- Aircraft radar course/height, improved swept-wing icons, head-only altitude chevrons and the24-pixel offscreen safe zone remain from0.12.4. Sound banks/codebooks are unchanged.

Range is decoded from the audio signal; overall loudness is not the trigger. Range alone cannot prove intent or a hit. When direction is unreliable, an urgent close flyby can spend flares. There is no evasion or total-response-time guarantee. Read `RANGE-PRIORITY-CM.txt` and the release notes for exact limits and standalone evidence.

Fourteen missile signatures, three cockpit references, and eight independent aircraft-engine-source codes across247 exterior engine events. Capacity is not guaranteed unique-aircraft count; team/model are unknown, game source creation limits range, and aircraft markers are desktop-only. Physical-headset validation is not claimed.

Experimental software for the user's separate/offline diagnostic setup. All in-game testing belongs to the user. GitHub releases are published deliberately; the repository is not a live source mirror.
