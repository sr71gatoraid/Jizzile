# Jizzile

[Download the latest portable release](https://github.com/sr71gatoraid/Jizzile/releases/latest)

Current release: **0.20.4 - Squad lobby reliability**.

The Squad window shows your current lobby, named members and position status.
Join with one click and rejoin saved squads. Leaving, paused sharing and brief
disconnects no longer delete the lobby for everyone. The hosted relay is updated.

Extract the full portable folder and run `Jizzile.exe`. Existing users can use
**Check for updates** to download only changed components. Preserve `Data`.
This update changes three app components; sound banks remain unchanged.

Teammate markers require valid, fresh coordinates and the same actual battle.
Public lobbies are discoverable by anyone; callsigns are not verified identities.
In-game testing remains with users. The reported VR marker visibility issue
remains unresolved.

This public repository distributes binaries and update manifests. Application
source remains local.
